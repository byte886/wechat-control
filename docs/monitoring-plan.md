## 二、监控维度

### 2.1 按会话类型

| 维度 | 说明 | 实现方式 |
|------|------|----------|
| 全部私聊 | 监控所有一对一聊天 | 遍历所有非 @chatroom 会话 |
| 全部群聊 | 监控所有群聊 | 遍历所有 @chatroom 会话 |
| 指定联系人 | 只监控特定好友 | 配置 wxid 白名单 |
| 指定群聊 | 只监控特定群 | 配置群 wxid 白名单 |
| 排除列表 | 不监控某些会话 | 配置黑名单 |

### 2.2 按触发条件

| 触发条件 | 说明 | 优先级 |
|----------|------|--------|
| @我 | 群聊中 @当前用户 | 高 |
| @all | 群聊中 @所有人 | 高 |
| 关键词 | 消息包含指定关键词 | 中 |
| 特定人 | 指定联系人发的任何消息 | 中 |
| 转账/红包 | 涉及金钱的消息 | 高 |
| 语音消息 | 任何语音消息（自动转写） | 中 |
| 文件/链接 | 任何文件或链接消息 | 低 |
| 未读消息 | 累计未读超过阈值 | 中 |

### 2.3 重要消息判定规则（推荐默认）

**高优先级（立即推送）：**
1. 转账消息（local_type=141733920817）
2. 私聊中特定人（如家人、老板、客户）的任何消息
3. 群聊中 @我 或 @all
4. 包含紧急关键词（如"紧急""马上""立刻"）

**中优先级（汇总推送）：**
1. 语音消息（自动转写后推送）
2. 红包消息
3. 文件/链接消息
4. 包含自定义关键词的消息
5. 合并聊天记录

**低优先级（仅记录，不推送）：**
1. 表情消息
2. 图片消息（可配置是否推送）
3. 视频消息
4. 系统消息（撤回、入群等）
5. 通话记录

### 4.3 数据流

```
1. 采集：轮询 wx new-messages / 直查数据库 → 原始消息列表
2. 过滤：按会话白名单/黑名单过滤 → 待处理消息
3. 解析：识别消息类型 → 解析内容（文字直接用/语音转写/图片OCR）
4. 识别：发送者 wxid → 昵称/备注名 → 完整消息对象
5. 判定：重要性评分 → 高/中/低优先级
6. 去重：msg_id 去重 → 新消息
7. 限流：频率控制 → 立即推送/汇总/丢弃
8. 推送：按优先级选择渠道 → 输出
9. 记录：写入日志文件 → 历史记录
```

## 六、风控与安全

### 6.1 只读操作安全
- 所有监控操作均为**只读**，不修改微信数据库
- 不注入、不 hook、不修改微信进程
- 仅通过 SQLCipher 读取数据库文件
- 风险等级：低（与手动查看聊天记录相当）

### 6.2 写操作风控（如启用自动回复）
- 频率限制：每分钟≤3、每小时≤20、同一对象5分钟≤2
- 夜间静默：23:00-08:00 暂停
- 黑名单：10类敏感内容不发
- 发送前验证：OCR 确认聊天对象
- 仅小号测试：写操作先在小号验证

### 6.3 隐私保护
- 所有消息数据仅存储在本地
- 日志文件可配置加密/自动清理
- 不上传任何消息内容到外部服务
- 推送渠道（如飞书）需用户明确授权
