# 03 · 需求澄清与技术规范 · wechat-control

> 补立项日期：2026-09-16 ｜ 方法：idea-to-tickets 的 clarify（澄清）→ spec（规范）两模式。
> 本文档第一部分是共识小结，第二部分是可交接、可验收的技术规范。记决策与行为，不记文件路径与代码。

---

## 第一部分 · 澄清共识小结

### 1. 核心需求（一句话）

让 AI 能用自然语言查询和总结我的微信本地数据（只读为主），并在严格风控下仅对小号开放受控发消息；工具本身可公开、可双机同步、可冒烟验证。

### 2. 用户场景

| 场景 | 触发说法 | 期望行为 |
|---|---|---|
| 信息检索 | "XX 群最近聊了什么？" | AI 调只读查询，返回摘要，不展示原始长文 |
| 未读扫雷 | "我有哪些未读？" | 返回未读会话列表 + 高优先级摘要 |
| 关键词搜索 | "搜一下关于 XX 的消息" | 全库搜索，按时间倒排，标注来源会话 |
| 人员盘点 | "XX 群有哪些人？" | 返回群成员列表（昵称/备注） |
| 活跃度 | "XX 群最近活跃度怎么样？" | 返回近 N 天消息数趋势 |
| 附件 | "XX 群最近发了哪些图片/文件？" | 返回附件列表，不自动下载原图 |
| 朋友圈/公众号 | "朋友圈/公众号最近有什么？" | 返回最近条目摘要 |
| 每日总结 | （自动） | daemon 每日产出一份消息摘要 |
| 受控发送 | "帮我给 XX 发一句：YY" | 仅小号，OCR 校验对象，频率硬闸，发送前确认 |

### 3. 关键决策（已定，不再讨论）

| # | 决策 | 为什么这么定 |
|---|---|---|
| D1 | 技术底座选 `jackwener/wx-cli`（Rust），自己不重写密钥提取 | 上游已解决 SQLCipher 4 解密与密钥扫描，重写成本高、风险大 |
| D2 | 微信锁版本 ~4.1.8 | 4.1.10+ 密钥内存格式变更，wx-cli 扫不到；关自动更新维持 |
| D3 | 密钥提取 = 关 SIP + `sudo wx init`，不重签、不 Frida | 重签+持续注入曾触发强制下线+违规提示，是红线 |
| D4 | 不做微信多开，用"单官方 App 内切换账号 + wx-account.sh" | 多开技术不可行且高风控；单 App 切账号是可行替代 |
| D5 | 多账号能力在本人 fork `third-party/wx-cli`（git 子模块），不用官方 npm 版 | 官方 npm 版无多账号，fork 是唯一路径 |
| D6 | 只读为主体，写操作严格隔离到小号 alt | 主号风控代价不可接受；只读零风控 |
| D7 | 写操作频率硬闸：1min≤3 / 1h≤20 / 同对象 5min≤2 / 23:00–08:00 静默 | 避免行为模型像机器人触发风控 |
| D8 | 公开仓，个人数据三归宿（脱敏明文 / `.enc` / 删除） | 公开仓本身是决策（D9），隐私靠纪律不靠藏仓库 |
| D9 | 仓设为 public | 个人学习工具，公开可接受；零隐私底线靠三归宿纪律保证 |
| D10 | 双机同步：先子模块后父仓提交，对端 ff-only | 子模块指针错序会导致父仓与子模块状态错位 |

### 4. 放弃了什么（备选否决记录）

## 第二部分 · 技术规范（Spec）

### 1. 问题（现状与痛点）

技能已建成三阶段能力，但缺正式治理：文档冗余、隐私加固未闭环、无可重复冒烟、双机同步未验证、MCP server 与文档不一致。本 spec 约束"治理整顿期"的行为与验收，不改三阶段能力本身。

### 2. 方案（选定方向）

在不动运行面能力的前提下，做一轮垂直切片式治理：清理文档 → 修代码质量 → 加固隐私 → 修可移植性 → 建冒烟 → 验双机 → 补 MCP。每一步可独立开工、独立验收（见 `04_工单切片.md`）。

### 3. User Stories（每条可验收）

> 角色统一为"使用本技能的 AI Agent / 本人"。每条都能转成测试。

**US-1 · 只读查询一致性**
作为 AI Agent，当用户问"XX 群最近聊了什么"时，系统应返回结构化摘要（消息数、时间范围、要点），且不修改任何微信本地文件、不联网、不操作微信界面，以便我放心回答而不触发风控。
验收：执行任一只读命令后，微信数据库 mtime 不变、无出站连接、无微信 UI 弹窗。

**US-2 · 版本锁定可验证**
作为维护者，我需要一条命令确认本机微信版本 = 4.1.8 且自动更新关闭，以便我在每周自查时 30 秒内判断是否踩雷。
验收：版本检查命令退出码 0 时打印 `wechat=4.1.8 auto_update=off`；任一不满足退出码非 0 并打印差异。

**US-3 · 写操作账号隔离**
作为用户，当我误在主号 main 上触发发送命令时，系统应物理拒绝（不调用 UI 自动化），并打印"写操作仅限小号 alt"，以便我主号永远安全。
验收：在 main 配置下调用发送命令，进程退出码非 0，微信界面无任何变化。

**US-4 · 写操作频率硬闸**
作为用户，当我短时间内连续发送超过阈值时，系统应拒绝后续发送并打印剩余冷却时间，以便我不会因密集发送触发风控。
验收：连发 4 条（同对象）时第 3 条之后被拒；夜间 23:00–08:00 任一条被拒；拒绝事件落日志。

**US-5 · 发送前对象校验**
作为用户，当我要求给"张三"发消息时，系统应在点击发送前 OCR 当前微信窗口标题，确认接收方匹配后才发送，以便不会发错人。
验收：OCR 不匹配时停止发送并要求用户二次确认。

**US-6 · 隐私零泄漏**
作为维护者，我需要一条扫描命令在公开仓当前树内查无真实 wxid、真实手机号、真实昵称、`Msg_<MD5>` 会话分表清单，以便 push 前自证清白。
验收：扫描命令退出码 0 表示零命中；命中时打印命中文件与行号。

**US-7 · 双机一致**
作为维护者，我在 `.8` 与 `.9` 两台机上 checkout 同一 commit 后，运行同一条冒烟命令应得到相同退出码，以便我相信双机是同一份代码。
验收：两机 `git rev-parse HEAD` 相同、子模块指针相同、冒烟退出码相同。

**US-8 · 可移植性**
作为维护者，代码与文档中不应出现硬编码用户名路径，所有路径用 `~` 或相对路径，以便换机器/换用户名不破坏。
验收：全仓 grep `/Users/<用户名>`（或本机真实用户名）零命中。

**US-9 · 冒烟一键化**
作为维护者，我需要 `scripts/smoke.sh` 一条命令跑完 10 类只读 + 写操作 dry-run，退出码 0 即代表健康，以便每周自查 5 分钟收口。
验收：干净环境下 `bash scripts/smoke.sh` 退出码 0；任一子项失败时非 0 并打印失败项。

**US-10 · MCP server 可用**
作为上层 Agent，我需要通过 STDIO 连接 MCP server 后至少能调用 3 个只读工具（sessions / search / unread），以便把微信查询能力暴露给 MCP 生态。
验收：`mcp-server/server.py` STDIO 启动无报错；列出工具 ≥ 3；调用 sessions 返回非空列表。

### 4. 已定的实现决策（含放弃的备选）

- **底座**：Rust wx-cli 做密钥提取与解密，Python 做上层业务（监控/转写/发送），Shell 做账号切换与 UI 自动化。不重写 Rust 层。
- **密钥**：关 SIP + `sudo wx init`，一次提取长期有效；不重签、不 Frida。
- **多账号**：单 App 内切换（`wx-account.sh`），fork `third-party/wx-cli`；不做多开。
- **写操作**：AppleScript + cliclick 操作 UI，不走微信协议层；频率/夜间/黑名单/OCR 四级硬闸。
- **语音**：SILK V3 解码走 `tools/silk-v3-decoder`，ASR 走本地 FunASR SenseVoiceSmall，不上云。
- **存储**：公开仓 + 三归宿；含个人数据的文件不入库、仅本地或加密 `.enc`。
- **同步**：git 子模块（wx-cli fork）+ 先子后父提交 + 对端 ff-only。

### 5. 测试决策（在哪测、测什么边界）

- **接缝（seam）**：所有治理行为都收敛到 `scripts/smoke.sh` 这一条最高接缝——AI/维护者只测它，不测内部每个脚本。冒烟通过 = 健康。
- **测什么边界**：
  - 只读 10 类命令各跑一次，断言返回非空且 JSON 可解析。
  - 写操作走 dry-run（不真发送），断言频率闸/账号闸/夜间闸/对象校验各触发一次拒绝。
  - 隐私扫描：`git grep` 正则扫当前树。
  - 可移植性：grep 硬编码用户名。
- **不测什么**：不测 FunASR 模型精度（外部依赖）；不测微信 UI 元素在不同 macOS 版本的像素位置（脆弱）；不测真实发送成功（走 dry-run）。

### 6. 不做什么（Out of Scope，重申）

加好友 / 删好友 / 发朋友圈 / 公众号发布 / 多开 / 重签微信 / Frida 注入 / 主号写操作 / 消息正文入公开仓 / 云端 ASR / 主动升级微信。详见 `01_范围与边界.md` §2。
