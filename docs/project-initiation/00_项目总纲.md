# 项目总纲 · wechat-control

> 最后更新：2026-09-17 ｜ 状态：Active ｜ 健康灯：🟡 At Risk（功能已建成；治理欠账部分偿还——T-07 已完成、AGENTS 接手手册与 ROADMAP 状态看板已建，冒烟体系/双机同步/git 历史隐私清理仍未完）
> 性质：**回溯性立项**——技能已实际建成三阶段能力，本总纲为补做正式立项材料，不是从零开工。

## 1. 一句话目标

把微信本地数据（会话/历史/联系人/群成员/未读/朋友圈/公众号/附件）通过解密本地 SQLite 的方式，安全、只读、零风控地交到 AI 手上做自然语言查询与每日总结；并在严格风控下仅对小号开放受控写操作（发消息/自动回复），做成一个**可公开、可双机同步、可冒烟验证**的个人技能。

## 2. 成功标准（可量化）

- [ ] **只读查询冒烟通过率 100%**：`sessions / history / search / contacts / group members / unread / stats / moments / official-account / attachment` 十类只读命令在干净环境下各跑一次，全部返回结构化结果、不 crash、不泄漏个人标识。
- [ ] **公开仓零隐私**：`git grep` 扫描仓内（含历史之外的当前树）无真实 wxid、真实昵称、真实手机号、`Msg_<MD5>` 会话分表清单、库文件绝对大小/条数；个人数据严格走三归宿（脱敏明文 / `.enc` / 删除）。
- [ ] **双机一致**：`.8`（本机）与 `.9`（对端）两台机在同一 commit 下，`git status` 干净、子模块 `third-party/wx-cli` 指针一致、冒烟结果一致；同步流程遵守"先子模块后父仓提交、对端 ff-only"。
- [ ] **SKILL.md 运行面加载面 ≤ 400 行**：AI 加载本技能时只需 `SKILL.md` + 按需 `references/`，`docs/` 不进运行面；主文档主体（不含 references 展开）保持可一次性读完。
- [ ] **写操作风控硬闸生效**：发送/自动回复仅在 `alt` 账号启用；每分钟 ≤3、每小时 ≤20、同对象 5 分钟 ≤2、23:00–08:00 静默，任一越限即拒绝发送并落日志；主号 `main` 上写操作命令物理拒绝。
- [ ] **锁版本纪律可验证**：本机微信版本 = 4.1.8，自动更新关闭；`wx --version` 与 `third-party/wx-cli` fork 指针在文档中可查。
