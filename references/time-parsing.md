# 自然语言时间解析规则（wechat-control 参考）

> 用于把用户自然语言中的时间表达，解析成 wx-cli 的 `--since` 和 `--until` 参数（格式 YYYY-MM-DD）。
> 当前基准日期：运行时动态获取，以下示例基于 2026-09-10。

## 规则表

| 用户表达 | 解析结果 | 示例（基准 2026-09-10） |
|---------|---------|------------------------|
| 今天 / 今日 | `--since 今天` | `--since 2026-09-10` |
| 昨天 / 昨日 | `--since 昨天 --until 今天` | `--since 2026-09-09 --until 2026-09-10` |
| 前天 | `--since 前天 --until 昨天` | `--since 2026-09-08 --until 2026-09-09` |
| 最近一周 / 近7天 / 过去一周 / 这一周 | `--since 7天前` | `--since 2026-09-03` |
| 最近两周 / 近14天 | `--since 14天前` | `--since 2026-08-27` |
| 最近一个月 / 近30天 / 过去一个月 | `--since 30天前` | `--since 2026-08-11` |
| 最近三个月 / 近90天 | `--since 90天前` | `--since 2026-06-12` |
| 最近半年 / 近180天 | `--since 180天前` | `--since 2026-03-15` |
| 最近一年 / 近365天 | `--since 365天前` | `--since 2025-09-10` |
| 本周 / 这个星期 | `--since 本周一` | `--since 2026-09-07`（周一） |
| 上周 / 上个星期 | `--since 上周一 --until 本周一` | `--since 2026-08-31 --until 2026-09-07` |
| 本月 / 这个月 | `--since 本月1号` | `--since 2026-09-01` |
| 上月 / 上个月 | `--since 上月1号 --until 本月1号` | `--since 2026-08-01 --until 2026-09-01` |
| 今年 / 这一年 | `--since 今年1月1号` | `--since 2026-01-01` |
| 去年 | `--since 去年1月1号 --until 今年1月1号` | `--since 2025-01-01 --until 2026-01-01` |
| N天前 / 最近N天 | `--since N天前` | "最近3天" → `--since 2026-09-07` |
| N周前 / 最近N周 | `--since N*7天前` | "最近2周" → `--since 2026-08-27` |
| N个月前 / 最近N个月 | `--since N*30天前`（近似） | "最近2个月" → `--since 2026-07-11` |
| X月X号之后 / 从X月X号开始 | `--since YYYY-MM-DD` | "9月1号之后" → `--since 2026-09-01` |
| X月X号到X月X号 / X月X号至X月X号 | `--since 开始 --until 结束` | "9月1号到9月5号" → `--since 2026-09-01 --until 2026-09-05` |
| X月X号之前 / 到X月X号为止 | `--until YYYY-MM-DD` | "9月5号之前" → `--until 2026-09-05` |

## 处理原则

1. **默认时间范围**：用户没说时间时，默认查最近 20 条消息（`--limit 20`），并在回答中说明"默认查了最近 20 条，需要更早或指定时间范围告诉我"。
2. **年份补全**：用户只说"9月1号"没说年份时，默认当前年份；如果是未来日期则回退到去年。
3. **模糊表达**：用户说"前段时间""之前""早些时候"等模糊表达时，默认最近 30 天，并说明假设。
4. **工作日/周末**：用户说"这周末""上周五"等，按当前周计算具体日期。
5. **时区**：默认用户本地时区（Asia/Shanghai, UTC+8）。

## 验证方法

用实际查询验证解析是否正确，例如：
- "张三最近一周聊了什么" → 应解析为 `wx history "张三" --since 2026-09-03`
- "测试群昨天发了什么" → 应解析为 `wx history "测试群" --since 2026-09-09 --until 2026-09-10`
- "这个月的未读消息" → 应解析为 `wx unread`（unread 不支持时间参数，需说明）

## 注意

- `wx unread` 命令不支持 `--since/--until` 参数，未读消息是实时状态，无法按时间范围筛选。
- `wx search` 支持 `--since/--until`。
- `wx history` 支持 `--since/--until` 和 `--limit`。
- `wx stats` 统计的是全量数据，不支持时间范围参数（统计整个会话的所有消息）。
